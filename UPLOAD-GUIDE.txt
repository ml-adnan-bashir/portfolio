UPLOAD GUIDE — portfolio update

1. Extract this ZIP. Upload its contents into the ROOT of your existing GitHub repository, keeping the folders as shown. Do not upload the ZIP itself or an enclosing changed-files folder.
2. Replace index.html and projects.html. Add the other files and lecture-apps folder. Keep all existing apps, pdfs, previews, builder files, and other assets.
3. Commit your upload and allow your existing GitHub Pages deployment to finish.

If an app needs separate images, scripts, styles, or data, upload those dependencies too, using the paths expected by that HTML. Browser-only apps work on GitHub Pages; server-side code needs its own service. Existing cached pages may need a refresh after deployment.
