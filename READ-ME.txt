PORTFOLIO BUILDER — START HERE

1. Open index-builder.html in desktop Chrome or Edge.
2. Choose Open portfolio folder and select this portfolio directory.
3. Customize the loaded portfolio and use Save to folder.
4. Review, commit, and push with Git.

The included starting pages are exactly the latest pages supplied in your ZIP.
Save also updates the builder defaults, so your next session starts from the
saved version. The alternate index-builder(1).html opens the same new builder.

Keep builder/ and builder-defaults.js beside index-builder.html.
See BUILDER-README.md for all controls, backup behavior, and the ZIP fallback.
