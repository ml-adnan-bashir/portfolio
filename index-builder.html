Your folder → your portfolio

  1. Extract this package and open index-builder.html in desktop Chrome or Edge.
  2. Click Open portfolio folder and select the folder containing your current index.html. Allow the browser to read and save files there.
  3. Customize your content, colors, fonts, sections, images, equations, and signal. The preview updates as you edit.
  4. Click Save to folder. Changed pages, design settings, fresh builder defaults, and uploaded assets are written into that same folder.
  5. Review the result in your usual Git workflow, then commit and push.

The builder first opens the exact pages included in this package. Opening your folder loads its latest pages. Browser drafts are offered separately, so an old draft never silently replaces your files.

Each save backs up changed existing files inside .portfolio-backups/. Existing apps, PDFs, and other files are preserved. The builder adds a Git ignore rule for backups when saving.

If folder access is unavailable, use Download update ZIP and merge its contents into your existing portfolio folder. This ZIP contains updated pages and new assets; it does not copy the original app and PDF collection.

If your browser blocks folder access when opening the HTML directly, run py -m http.server 8000 --bind 127.0.0.1 inside your portfolio folder, then open the local builder.

Saving updates your local files. Use Git to commit and push them. Preview visits never increment the shared visit counter.
