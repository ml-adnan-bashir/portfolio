      Lab guide & model assumptions

      Select a case, predict the path, then use Step for one decision or Run for automatic playback. Select a device on the map to inspect its interfaces. Read the packet headers beneath each trace entry.

      The field station uses Starlink in the lecture scenario. R1 is the lab’s IP boundary between two directly connected /24 LANs. The satellite, radio link and provider network are abstracted. All devices and packets here are simulated locally.

      Hosts start with resolved neighbour addresses and switches have populated MAC tables. Each host sends remote traffic to its default gateway. R1 checks its routing table, decrements the IPv4 TTL and rewrites the Ethernet header. A reply is a new packet. UDP is a single datagram.

      User policies match IPv4 endpoints, packet type and ingress port before normal forwarding. Source and destination roles reverse on an echo reply. Priority 0 is the fixed permit fallback. Case checks run separate probes and leave your visible counters alone. Case settings are saved in this browser when local storage is available.
